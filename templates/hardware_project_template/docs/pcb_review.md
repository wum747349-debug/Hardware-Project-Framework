## 使用方式与事实边界

- 阶段 5 可创建本文件，只填写 Layout Preflight 结论。
- 阶段 6 记录需要跨回合追踪的重要布局和布线问题。
- 阶段 7 填写 Release Review、Batch DRC、豁免、制造输出和放行结论。
- 文件存在或提前创建不表示 PCB 审查完成，也不表示可以制造。
- `.PcbDoc` 是权威源；图片不能证明网络、精确规则命中、铺铜或 DRC 通过。
- 用户负责 Altium 规则配置、布局布线、Repour、完整 Batch DRC 和制造输出；AI/Codex 只分析用户提供的证据。
