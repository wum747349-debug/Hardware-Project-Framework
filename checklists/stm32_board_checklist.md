# STM32 硬件检查表

## 电源

- [ ] 所有 VDD 已连接
- [ ] 所有 VSS 已连接
- [ ] 每个 VDD 附近有 0.1uF 去耦电容
- [ ] 3.3V 电源容量满足 MCU 和外设需求
- [ ] VDDA 是否按要求连接和滤波
- [ ] VREF+ 是否处理合理
- [ ] 3.3V 测试点已预留

## 复位和启动

- [ ] NRST 有合理复位电路
- [ ] BOOT0 有默认下拉
- [ ] 启动模式明确

## 时钟

- [ ] 晶振靠近 MCU
- [ ] 晶振负载电容按规格计算
- [ ] 晶振走线短且对称

## 调试接口

- [ ] SWDIO 引出
- [ ] SWCLK 引出
- [ ] NRST 引出
- [ ] GND 引出
- [ ] 3.3V 参考电压引出

## 通信接口

- [ ] UART TX/RX 方向清楚
- [ ] 板载 USB-UART 与外部 UART 扩展未复用同一组 MCU 引脚
- [ ] 外部 UART TX/RX 从 MCU 视角标注清楚
- [ ] I2C 有合适的 3.3V 上拉；若当前依赖外接模块上拉，应在原理图审查记录中明确
- [ ] I2C 裸器件接入场景已评估是否需要预留 SCL/SDA 上拉焊盘
- [ ] SPI 片选信号清楚
- [ ] 接口电平明确
- [ ] 5V 系统电源外引时已标注用途和反灌风险

## 用户 IO

- [ ] 用户 LED GPIO、限流电阻、点亮电平明确
- [ ] 用户按键 GPIO、上下拉方式、按下电平明确
- [ ] GPIO 扩展排针脚位与 Pin Map 一致

## ADC

- [ ] ADC 输入范围不超过 MCU 允许范围
- [ ] ADC 输入有串联限流电阻
- [ ] ADC 输入有 RC 滤波
- [ ] 模拟信号远离高频和大电流区域

## MOSFET 输出

- [ ] MOSFET 适合 3.3V 逻辑驱动
- [ ] 漏源耐压满足需求
- [ ] 电流能力满足负载需求
- [ ] 感性负载有续流路径
- [ ] 大电流走线宽度足够
