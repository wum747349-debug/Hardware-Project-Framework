# PCB Release Checklist

> 文档状态：通用模板
> 当前阶段：阶段 7：PCB 审查阶段
> 适用对象：待 PCB Release Review 与制造放行的项目和硬件版本
> 最后核对依据：项目事实文件、当前 PCB 实现证据、完整 Batch DRC 与同版制造输出
> 最近更新：2026-07-31

## 使用说明

- 将本清单复制或引用到当前项目 `docs/pcb_review.md` 后填写。
- `状态` 建议使用：`待核对`、`不适用`、`不通过`、`已确认`、`已豁免`。
- `不适用` 和 `已豁免` 必须填写依据、风险和批准记录。
- 勾选不代表 AI 或 Codex 已运行 Altium、Repour 或 Batch DRC；实际 EDA 操作和制造输出必须由用户执行并确认。
- 制造放行必须在最后填写显式结论，不能由清单完成率自动推导。

- [ ] 每项豁免只覆盖明确对象。
