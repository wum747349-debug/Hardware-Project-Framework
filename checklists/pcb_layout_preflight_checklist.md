# PCB Layout Preflight Checklist

> 文档状态：当前有效
> 适用阶段：阶段 5：PCB 布局阶段
> 适用对象：待进入正式 PCB 布局的项目与硬件版本
> 最后核对依据：项目事实文件、目标板厂官方能力、关键器件资料与用户 EDA 确认

## 使用说明

- 将本清单复制或引用到当前项目 `docs/pcb_review.md` 后填写。
- `状态` 使用：`待核对`、`已确认`、`不通过`、`不适用`。
- `不适用` 必须在“依据 / 证据”中说明理由。
- Altium Designer 的实际配置和人工核对由用户确认；图片或文档不能替代 EDA 实现证据。
- Layout Preflight 不要求初始 DRC，也不以 DRC 作为批准正式布局的门禁。
- 任一高风险阻断项未关闭时，不批准开始正式布局。
