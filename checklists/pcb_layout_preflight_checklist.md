# PCB Layout Preflight Checklist

> 文档状态：通用模板
> 当前阶段：阶段 5：PCB 布局阶段
> 适用对象：待进入正式 PCB 布局的项目与硬件版本
> 最后核对依据：项目事实文件、目标板厂官方能力、关键器件资料与用户 EDA 确认
> 最近更新：2026-07-31

## 使用说明

- 将本清单复制或引用到当前项目审查记录后填写。
- `状态` 建议使用：`待核对`、`不适用`、`不通过`、`已确认`。
- `不适用` 必须填写依据。
- 勾选只表示记录已填写，不证明 Altium Designer 已配置或验证；EDA 状态必须有用户确认或证据路径。
- 任一高风险阻断项未关闭时，不得批准开始正式布局。
