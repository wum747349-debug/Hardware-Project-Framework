# 锂电池电源板安全检查表

- [ ] USB-C VBUS 接线正确

- [ ] 充电 IC 选型适合单节锂电池

- [ ] 充电状态 LED 接法正确
- [ ] 芯片散热铜皮足够

- [ ] 过充保护
- [ ] 过放保护
- [ ] 过流保护

- [ ] 3.3V 测试点已预留
