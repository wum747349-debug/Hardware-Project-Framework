# 电池 / 电源安全条件参考片段

> 定位：optional domain reference；适用于实际存在电池、充电或多电源路径的项目。
> 不预设 USB-C、单节锂电池、固定输出电压或充电拓扑；不是 Universal Hardware Checklist。

按 [AI Context Guide](../docs/AI_Context_Guide.md) 从实际电源树、电池规格、芯片官方资料和项目风险推导适用项。通用输入保护、稳压外围、功耗与接口极性由 [Schematic Core](schematic_checklist.md) 覆盖，散热由 [PCB Core](pcb_layout_checklist.md) 覆盖，首次受控上电由 [Bring-up Core](bringup_test_checklist.md) 覆盖。

## 电池与充电 — 存在时

- [ ] 充电器与电池化学体系、串联节数、电压范围及电池厂商限制匹配。
- [ ] 充电电流、终止条件、温度限制及设定外围有官方依据；状态输出 / 指示连接与真实状态含义一致。
- [ ] 过充、过放、过流、短路与适用温度保护的责任器件、阈值依据及失效边界明确；不能把充电控制等同于全部电池保护。
- [ ] 电池接口极性、插拔、误接及裸露端子短路风险已处理。

## 多电源与负载路径 — 存在时

- [ ] 电池、外部输入和负载之间的切换、同时供电、反灌及掉电路径符合实际架构。
- [ ] 边充边用、启动负载或负载瞬变不会破坏充电判定、保护与热边界；不适用时说明原因。
- [ ] 每条实际输出轨的负载、电压与余量已由 Project Facts 确定，不继承固定 3.3V 等默认值。

## 安全测试补充

- [ ] 测试供电组合、连接顺序、限流与隔离依据实际拓扑制定；不机械套用“先不接电池”步骤。
- [ ] 接入电池前已确认极性、输出状态与故障隔离方式；充电测试有监护、温度观察及异常停止条件。

适用检查与结果分别进入当前 `docs/schematic_review.md`、`docs/pcb_review.md` 或 `docs/bringup_log.md` / `docs/test_report.md`，不默认另建电池清单文件。
