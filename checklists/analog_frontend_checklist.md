# 模拟前端检查表

## 输入

- [ ] 输入信号范围明确
- [ ] 输入电压不会超过运放和 ADC 允许范围
- [ ] 输入端有必要的限流和保护
- [ ] 输入接口极性和方向清楚

## 运放

- [ ] 供电电压满足要求
- [ ] 输入共模范围满足要求
- [ ] 输出摆幅满足 ADC 输入范围
- [ ] 带宽满足信号频率要求
- [ ] 压摆率满足要求
- [ ] 失调电压满足精度需求
- [ ] 去耦电容靠近运放电源脚

## 滤波

- [ ] RC 截止频率有计算依据
- [ ] 滤波器不会影响目标信号
- [ ] ADC 采样前信号稳定

## ADC

- [ ] ADC 输入范围明确
- [ ] 参考电压稳定
- [ ] ADC 输入阻抗满足要求
- [ ] 采样率满足需求
- [ ] 采样噪声有测试计划

## PCB

- [ ] 模拟输入远离大电流路径
- [ ] 参考电压远离噪声源
- [ ] 模拟地回流路径合理
- [ ] 关键信号测试点已预留
