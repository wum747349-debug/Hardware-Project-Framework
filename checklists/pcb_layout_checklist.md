# PCB Layout / Routing Review Checklist

> 文档状态：当前有效
> 适用阶段：阶段 5：PCB 布局阶段、阶段 6：布线和铺铜阶段
> 适用对象：进行 PCB 布局、布线、回流与铺铜审查的项目和硬件版本
> 最后核对依据：当前 PCB 实现证据、项目 PCB 规则和关键器件 Layout 资料

## 使用说明

- 本 Checklist 用于 PCB Skill 的 `Layout / Routing Review` 模式，可复制或引用到当前项目的审查过程。
- `状态` 建议使用：`待核对`、`已确认`、`不通过`、`不适用`、`待 EDA 核对`；`不适用` 应说明理由。
- AI/Codex 只分析用户提供的 PCB 图片和其他实现证据。图片不能证明网络连接、精确间距、线宽、孔径、环宽、规则命中、铺铜状态或 DRC 通过。
- 阶段 5 和阶段 6 不要求正式 Batch DRC；阶段 6 不要求保存、导出或归档中间 DRC。用户可按需使用实时检查或临时检查，但中间 DRC 不是仓库门禁。
- 用户负责在 Altium Designer 中实际布局、布线、换层、铺铜和 Repour，并确认当前实现版本。
- 只把需要跨回合追踪的重要问题记录到 `docs/pcb_review.md`；普通即时建议不强制写入项目审查记录。
- 无法由当前证据确认的实现项标记为 `待 EDA 核对`，不得仅凭视觉整洁判定电气正确或可制造。

| 检查项 | 结论 | 依据 / 证据 | 状态 |
|---|---|---|---|
| 板框闭合，外形、圆角、尺寸和异形结构符合当前机械目标 |  |  |  |
| 安装孔、禁布区、板边边界和孔周围空间合理 |  |  |  |

## 3. 电源、保护、去耦和热

| 检查项 | 结论 | 依据 / 证据 | 状态 |
|---|---|---|---|
| 电源入口与保险丝、反接保护、浪涌或过压保护的物理顺序符合设计意图 |  |  |  |
| ESD、TVS 等接口保护器件靠近能量或干扰入口，保护路径短且回流明确 |  |  |  |
| 稳压器输入、输出电容靠近相应引脚，局部回路短且连接清楚 |  |  |  |
| MCU 和关键芯片去耦电容靠近电源脚，去耦与地回路短且直接 |  |  |  |
| 电源入口、转换器、负载和续流路径等关键电流环路紧凑 |  |  |  |
| 大电流走线、过孔和铜皮没有不合理细颈、急剧缩窄或电流瓶颈 |  |  |  |
| MOSFET、二极管、稳压器和其他功率器件的铜面积、过孔与散热条件合理 |  |  |  |
| 电源地回流和高电流路径不会明显穿越或切割模拟、参考和其他敏感区域 |  |  |  |

## 4. 模拟、晶振、高速与敏感网络

| 检查项 | 结论 | 依据 / 证据 | 状态 |
|---|---|---|---|
| 晶振及负载器件靠近目标芯片，路径短，回流连续且远离强噪声源 |  |  |  |
| 模拟输入、参考电压和高阻节点远离开关节点、时钟、大电流和数字噪声源 |  |  |  |
| ADC、运放、参考源及其去耦、滤波器件的局部布局符合信号流和资料要求 |  |  |  |
| USB、差分或其他高速接口路径紧凑，参考面和回流路径连续 |  |  |  |
| 外部接口的 ESD 器件靠近连接器，接口侧与受保护侧路径关系清楚 |  |  |  |
| 敏感网络未跨越地分割、参考面缺口或大电流回流区域 |  |  |  |
| 关键器件 datasheet / application note 的专项 Layout 要求已落实或列为待核对 |  |  |  |

## 5. 布线、换层、回流和过孔

| 检查项 | 结论 | 依据 / 证据 | 状态 |
|---|---|---|---|
| 总体 routing / signal flow 清楚，无明显不必要绕行、长支线或悬空支路；需要特殊保护的 routing-critical functions / constraints 可从当前 Project evidence 识别，实际关键路径未明显破坏其 dominant constraints |  |  |  |
| 关键电源、负载、模拟、参考等适用路径满足当前 Project 的短、直接和隔离噪声目标；Ordinary / 较低关键度 routing 未明显占用 critical routing corridor，或破坏 return/reference continuity 与其他 dominant routing constraint |  |  |  |
| 关键网络没有不必要的反复换层，换层位置与路径目标一致 |  |  |  |
| 信号换层附近存在合理回流路径或地过孔，参考面连续性未被明显破坏 |  |  |  |
| 过孔数量和位置合理，密集区域没有造成局部拥挤、细颈或回流阻断 |  |  |  |
| 走线宽度变化平缓，没有急剧缩窄、尖锐转角或明显电流瓶颈 |  |  |  |
| 焊盘附近走线、热焊盘、散热焊盘和大铜连接兼顾电气、散热与可焊性 |  |  |  |
| 普通信号和回流路径没有穿越晶振、模拟、高阻或其他敏感区域 |  |  |  |

| 铜岛、孤立铜、狭长铜颈和被过孔/焊盘割裂区域已检查 |  |  |  |
| Polygon 与普通焊盘、过孔的连接方式符合项目规则和可焊性要求 |  |  |  |
| 热焊盘、功率焊盘和大电流连接方式符合散热与载流目标 |  |  |  |
| 板边、安装孔和机械禁布区附近铜皮满足当前设计边界 |  |  |  |
| 顶底层铺铜关系和地过孔策略能够支持连续回流，未形成明显屏蔽缝隙 |  |  |  |
