# 器件选型规则

## 总原则

- 优先选择资料完整、采购方便、封装易焊接的器件。
- 优先选择有官方 datasheet、application note 和参考设计的器件。
- 第一版不追求极限性能，优先保证可实现、可调试、可复盘。
- 不使用来历不明或参数不清晰的器件。

## MCU 选型

考虑因素：

- 封装是否容易焊接
- 外设是否满足 UART / I2C / SPI / ADC 需求
- 是否支持 SWD 调试
- STM32CubeMX 和 Keil 是否支持完善
- 资料和示例是否丰富

## 电源器件选型

考虑因素：

- 输入电压范围
- 输出电压
- 输出电流能力
- 静态电流
- 压差或效率
- 封装散热能力
- 输入输出电容要求
- 是否容易采购

## MOSFET 选型

考虑因素：

- VDS 最大耐压
- ID 电流能力
- RDS(on)
- VGS(th) 不是完全导通电压，不能只看阈值电压
- 是否适合 3.3V 逻辑驱动
- 封装散热能力

## 运放选型

考虑因素：

- 供电电压范围
- 输入共模范围
- 输出摆幅
- 带宽
- 压摆率
- 输入失调电压
- 输入偏置电流
- 噪声
- 是否适合单电源 3.3V / 5V 应用

## ADC 选型

考虑因素：

- 分辨率
- 采样率
- 输入范围
- 参考电压
- 接口类型
- 输入阻抗要求
- 噪声性能
