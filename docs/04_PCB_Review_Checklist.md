# PCB Review Checklist

## 布局检查

- [ ] 电源入口靠近板边
- [ ] 调试接口方便插拔
- [ ] 去耦电容靠近芯片电源脚
- [ ] 晶振靠近 MCU
- [ ] 模拟区域和数字区域有合理分区
- [ ] 大电流区域远离模拟输入
- [ ] 发热器件有足够铜皮散热
- [ ] 所有接口方向清楚
- [ ] 所有测试点可触达

## 布线检查

- [ ] 电源线宽度满足电流需求
- [ ] GND 尽量完整
- [ ] 关键信号没有绕远路
- [ ] ADC 输入远离高频和大电流信号
- [ ] MOSFET 大电流回路尽量短
- [ ] USB、晶振、复位等信号走线合理
- [ ] 没有明显的地回流路径被割裂

## 制造检查

- [ ] DRC 无严重错误
- [ ] 板框闭合
- [ ] 丝印不压焊盘
- [ ] 封装方向正确
- [ ] Gerber 已检查
- [ ] BOM 已导出
