# 工具链配置说明

## EDA 工具

- Altium Designer

用于：

- 原理图设计
- PCB Layout
- 封装管理
- BOM 输出
- Gerber 输出
- 3D 预览
- 制造文件整理

## STM32 工具链

- STM32CubeMX：用于芯片选型、时钟树配置、外设初始化和代码生成
- Keil MDK：用于 STM32 固件开发、编译、下载和调试

## 版本管理

- Git
- GitHub

## 文档工具

- Markdown
- 截图工具
- 表格工具，例如 Excel

## 调试工具

建议准备：

- 万用表
- 可调直流电源
- ST-Link
- USB 转串口模块
- 逻辑分析仪
- 示波器
- 电烙铁
- 热风枪
- 镊子
- 助焊剂
