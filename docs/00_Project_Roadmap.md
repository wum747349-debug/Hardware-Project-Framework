# 项目路线图

## 阶段 1：STM32 数据采集/控制开发板

目标：完成一块 2 层 STM32 控制板，覆盖 MCU 最小系统、电源、ADC、通信接口、MOSFET 输出和调试接口。

主要能力：

- STM32 最小系统
- USB-C 供电
- 3.3V 电源
- SWD 调试
- UART / I2C / SPI 接口
- ADC 输入保护与滤波
- MOSFET 低边驱动
- 2 层 PCB Layout
- 上电调试

## 阶段 2：单节锂电池充电与保护电源板

目标：完成一块 USB-C 输入、单节锂电池充电与保护、电源输出的电源管理板。

主要能力：

- 单节锂电池充电
- 电池保护
- 3.3V 稳压输出
- 充电状态指示
- 电源路径理解
- 电源测试和安全调试

## 阶段 3：STM32 + 运放 + ADC 模拟信号采集板

目标：完成一块模拟信号采集板，覆盖运放前端、滤波、参考电压、ADC 采样和模拟 PCB 布局。

主要能力：

- 运放缓冲 / 放大
- RC 滤波
- ADC 采样
- 参考电压
- 模拟 / 数字区域布局
- 噪声测试
- 采样稳定性分析

## 最终作品集目标

三个项目最终组合成一个完整方向：

便携式多传感器数据采集与控制硬件平台，包括：

- STM32 数据采集/控制主板
- 单节锂电池电源管理板
- 模拟信号采集扩展板
