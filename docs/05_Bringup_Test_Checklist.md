# 上电调试检查表

## 上电前

- [ ] 目视检查焊接方向
- [ ] 检查芯片方向
- [ ] 检查电源芯片方向
- [ ] 万用表测输入电源与 GND 是否短路
- [ ] 万用表测 3.3V 与 GND 是否短路
- [ ] 检查连接器极性
- [ ] 检查测试点是否可用

## 第一次上电

- [ ] 使用限流电源
- [ ] 设置合理限流值
- [ ] 不直接接入昂贵外设
- [ ] 先测输入电压
- [ ] 再测 3.3V
- [ ] 观察电流是否异常
- [ ] 触摸或测量芯片是否异常发热

## 基础功能验证

- [ ] 电源正常
- [ ] 复位正常
- [ ] 调试器可连接
- [ ] LED 可控制
- [ ] 按键可读取
- [ ] UART 可通信
- [ ] I2C / SPI 可通信
- [ ] ADC 可采样
- [ ] MOSFET 输出可控制

## 记录要求

每次调试必须记录：

- 日期
- 板卡版本
- 输入电压
- 限流值
- 实测电流
- 关键电压
- 异常现象
- 定位过程
- 解决方案
