# 简历项目记录

本文件用于整理三个硬件项目最终可写入简历的内容。

## 项目 1：STM32 数据采集/控制开发板

可体现能力：

- STM32 最小系统设计
- 电源设计
- ADC 输入保护与滤波
- UART / I2C / SPI 接口设计
- MOSFET 输出驱动
- PCB Layout
- 样板焊接与调试

## 项目 2：单节锂电池充电与保护电源板

可体现能力：

- USB-C 输入
- 单节锂电池充电
- 电池保护
- 3.3V 稳压输出
- 电源测试
- 安全调试

## 项目 3：STM32 + 运放 + ADC 模拟信号采集板

可体现能力：

- 运放模拟前端
- RC 滤波
- ADC 采样
- 参考电压设计
- 模拟 PCB 布局
- 噪声与稳定性测试

## 最终包装方向

便携式多传感器数据采集与控制硬件平台。
