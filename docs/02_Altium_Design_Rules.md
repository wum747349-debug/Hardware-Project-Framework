# Altium Designer 设计规则

## 原理图规则

- 原理图按功能模块拆分，不把所有内容挤在一页。
- 电源、MCU、调试接口、ADC 输入、MOSFET 输出、通信接口应分块清晰。
- 所有接口必须标注方向、电压等级和功能。
- 所有关键电源网络必须命名清楚，例如 `VBUS_5V`、`3V3`、`BAT`、`GND`。
- 所有关键网络应预留测试点。
- 器件参数、封装、耐压、电流能力必须核对 datasheet。

## PCB 规则

- 第一版项目优先使用 2 层板，除非明确需要 4 层板。
- USB-C、电源接口、调试接口应靠近板边。
- 去耦电容必须靠近芯片电源脚。
- 晶振必须靠近 MCU。
- 模拟输入尽量远离 MOSFET、大电流和高频开关区域。
- 大电流路径走线加宽。
- 底层尽量保持完整地平面。
- 丝印不得压焊盘。
- 接口 1 脚方向必须明确。
- 打样前必须完成 ERC、DRC 和 Gerber 检查。

## 输出文件

每次准备打样前，至少输出：

- 原理图 PDF
- PCB 顶层截图
- PCB 底层截图
- 3D 预览图
- BOM
- Gerber
- 钻孔文件
- 贴片坐标，可选
- 制造说明，可选
