# PCB 审查提示词

请根据当前项目的 requirements.md、design_notes.md、PCB 截图和 3D 图，帮我审查 PCB Layout。

请重点检查：

1. 器件布局是否合理
2. 电源路径是否清晰
3. GND 是否完整
4. 去耦电容是否靠近芯片电源脚
5. 晶振、复位、SWD 是否合理
6. ADC / 模拟信号是否远离噪声源
7. MOSFET / 大电流路径是否合理
8. 接口方向和丝印是否清楚
9. 是否方便焊接和调试
10. 是否适合打样

请按以下格式输出：

1. 总体结论
2. 可以保留的地方
3. 必须修改的问题
4. 建议优化的问题
5. 打样前检查清单
