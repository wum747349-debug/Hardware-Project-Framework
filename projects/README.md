# Legacy Project History Marker

本 Framework Repository 的早期 Git history 曾包含三个真实硬件 Project。它们已完成迁移与 Authority Cutover，各自 Standalone Repository 是 Only Active Project Authority；Framework current Git tree 不再保存真实 Project copy。

历史来源可通过 Git history、`framework-pre-v1-migration` baseline tag 与 Repository Architecture Migration records 追溯。本 marker 只提供历史导航，不保存 Project facts、Hardware Stage、Framework binding、EDA、Manufacturing、Bring-up 或 Test 状态，也不构成第二事实源。

禁止在 `projects/` 下恢复活动 Project 开发或与 Standalone Repository 双写。任何 Project 工作必须在对应的活动权威仓库中进行。
