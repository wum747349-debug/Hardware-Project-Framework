# 设计说明

## MCU 选型

待定。候选型号包括：

- STM32F103C8T6
- STM32G030 / STM32G031
- STM32G431

第一版优先考虑资料丰富、易焊接、Keil 和 STM32CubeMX 支持完善的型号。

## 电源设计

USB-C 输入 5V，经稳压芯片转换为 3.3V，给 STM32 和外设供电。

## ADC 输入设计

ADC 输入需要考虑：

- 输入电压不能超过 MCU ADC 允许范围
- 输入端串联限流电阻
- 加入 RC 低通滤波
- 必要时增加钳位或 TVS 保护
- 预留测试点

## MOSFET 输出设计

MOSFET 输出用于控制小电流负载。第一版采用低边驱动结构，需要注意：

- MOSFET 是否能被 3.3V 逻辑充分驱动
- 负载电流是否超过 MOSFET 能力
- 感性负载需要续流路径
- 大电流走线需要加宽
