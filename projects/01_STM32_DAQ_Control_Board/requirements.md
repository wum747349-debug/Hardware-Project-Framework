# 项目需求

## 项目名称

STM32F103C8T6 数据采集/控制开发板

## 核心目标

设计一块基于 STM32F103C8T6 的 2 层 PCB 开发板，用于训练 STM32 最小系统、电源输入与保护、USB 转 UART 通信、ADC 输入采集、MOSFET 低边控制输出、常用通信接口扩展、PCB Layout、上电调试和测试验证能力。

第一版优先保证：

- 可实现
- 可焊接
- 可调试
- 器件常见易采购
- 文档和制造输出完整

第一版不追求复杂功能，不做高速接口，不做大电流输出，不做高精度模拟前端。

## 功能需求

### 0. PCB 尺寸与机械边界

- 第一版 PCB 尺寸暂定约 `70mm x 50mm`。
- 后续可根据接口数量、测试点位置、安装孔、走线和布局情况微调。
- 可预留 2-4 个安装孔，具体孔径、位置和禁布区后续在 PCB 结构规划阶段确认。

### 1. MCU 最小系统

- MCU 型号确定为 `STM32F103C8T6`。
- 封装优先按常见 LQFP48 方向考虑，后续原理图阶段需核对具体料号、封装和引脚定义。
- 需要包含 STM32 最小系统：
  - 3.3V 供电
  - VDD / VDDA / VSS / VSSA 处理
  - 去耦电容
  - NRST 复位
  - BOOT 配置
  - SWD 下载调试接口
  - 外部高速晶振

### 2. 外部晶振

- 外部高速晶振频率确定为 `8MHz`。
- HSE 晶振、电容、负载电容和启动配置后续必须根据 STM32F103C8T6 datasheet / reference manual 核对。

### 3. USB-C 供电与 USB 转 UART 通信

第一版不使用 STM32 原生 USB，不把 USB CDC 作为必做功能。

- USB-C 接口用于 5V 输入供电。
- USB-C 的 D+ / D- 连接 USB 转 UART 芯片，不连接 STM32 PA11 / PA12。
- STM32 PA11 / PA12 第一版完全不用作 USB 功能。
- USB 转 UART 芯片通过 TX/RX 与 STM32 USART 通信。
- 推荐使用 USART1：
  - USB 转 UART TXD -> STM32 USART1_RX / PA10
  - USB 转 UART RXD <- STM32 USART1_TX / PA9
- TX/RX 必须交叉连接。
- USB 转 UART 芯片与 STM32 之间的 UART 电平必须为 3.3V。
- 电脑端识别为 COM 串口，用于串口调试、打印日志、ADC 数据上传、MOSFET 控制命令下发和后续上位机通信实验。
- 需求阶段不直接确定 USB 转 UART 最终型号。
- 后续器件选型阶段可优先比较 `CH340C / CH340N`、`CP2102N`、`FT232RL / FT230X` 等方案。
- 比较维度包括供电方式、3.3V 逻辑电平支持、驱动支持、封装焊接难度、采购便利性和 datasheet 完整性。

### 4. 电源输入与保护

- USB-C 输入 5V。
- 5V 经电源保护和电源开关后，再转换为 3.3V。
- 3.3V 给 STM32、USB 转 UART 芯片逻辑侧、LED、接口上拉等低压电路供电。
- 需要包含：
  - 电源开关
  - 保险丝或自恢复保险丝
  - TVS / ESD 保护
  - 输入滤波
  - 3.3V 稳压电路
  - 电源指示 LED
  - 5V、3.3V、GND 测试点
- 可以单独预留若干个 `3.3V` 电源排针，用于给外部低功耗模块供电。
- 外部模块从板载 `3.3V` 取电时，最大电流限制为 `<=100mA`。
- `5V` 引脚主要用于测试点或低风险扩展。
- 后续若将 `5V` 作为外部供电输出，需要在原理图阶段结合 USB 输入保护、保险丝、电源开关和走线宽度重新核对。
- 3.3V 外供能力和 5V 扩展边界需要影响后续 LDO、保险丝、电源开关、电源测试点和排针选型。
- 保险丝、TVS、LDO、USB-C CC 电阻等器件参数后续必须根据 datasheet / application note 核对，需求阶段不写死具体型号。

### 5. ADC 输入

- ADC 输入通道数：2 路。
- 板级外部接口输入范围：`0-5V`。
- STM32 ADC 引脚实际输入范围：`0-3.3V`。
- STM32 ADC 引脚不能直接承受 5V，外部 0-5V 信号进入 MCU 前必须经过缩放和保护。
- 第一版 ADC 主要用于低速电压采集和功能验证。
- 目标采样频率按每通道 `10Hz-1kHz` 级别考虑。
- 不用于高速波形采集，不追求高精度模拟测量。

每路 ADC 输入建议包含：

- 电阻分压，将 0-5V 缩放到 0-3.3V 以内
- 串联限流电阻
- RC 低通滤波
- 必要的钳位或 TVS 保护预留/评估
- ADC 输入测试点
- GND 引脚

后续分压电阻、RC 滤波、采样时间、输入阻抗和保护器件需要围绕低速采集目标核对。

### 6. MOSFET 低边输出

- MOSFET 输出通道数：2 路。
- 输出形式：N-MOSFET 低边开关。
- 面向小电流负载，不做大电流输出。
- MOSFET 负载电源允许外部输入。
- MOSFET 外部负载电源 `VLOAD` 第一版建议限制在 `5V-12V`。
- `VLOAD` 最大不超过 `12V`。
- 第一版主要面向 5V/12V 小电流低压负载。
- 外部负载电源必须与板子 GND 共地。
- 推荐使用电流：`<=300mA`。
- 设计目标可按 `<=500mA` 预留。
- 若驱动感性负载，必须考虑续流路径或保护器件。

每路 MOSFET 输出建议包含：

- STM32 GPIO 控制
- 栅极串联电阻
- 栅极下拉电阻
- 输出端排针
- 外部 VLOAD / OUT / GND 标识
- MOSFET 栅极和输出节点测试点

后续器件选型阶段需要根据 3.3V 栅极驱动能力、Rds(on)、封装散热、负载电流、VLOAD 范围、续流二极管/TVS、接口、丝印和安全说明重新核对 MOSFET datasheet。

### 7. 接口形式

第一版接口形式暂定为排针。需要保留：

- SWD 下载调试接口
- USB-C 接口
- UART 通信/扩展接口
- I2C 传感器接口
- SPI 扩展接口
- 2 路 ADC 输入排针
- 2 路 MOSFET 输出排针
- 5V / 3.3V / GND 等电源测试点或扩展引脚

通信扩展接口电平边界：

- `UART / I2C / SPI` 扩展接口第一版均为 `3.3V` 逻辑。
- 不直接兼容 `5V` 逻辑信号。
- 如果外接 5V 模块，需要外部电平转换或重新评估保护方案。

当前原理图接口规划：

- 板载 CH340C 使用 USART1：`PA9 / USART1_TX`、`PA10 / USART1_RX`，不再接外部 UART 扩展排针。
- 外部 UART 扩展使用 USART2：`PA2 / TX2`、`PA3 / RX2`，TX2 为 MCU 发送，RX2 为 MCU 接收。
- I2C 扩展使用 I2C1：`PB6 / SCL`、`PB7 / SDA`，接口同时提供 `3.3V` 和 `GND`。
- 当前原理图暂未给 I2C 预留外部 `4.7k` 上拉电阻，依赖外接模块自带上拉或后续复审补 `R_SCL/R_SDA` 预留焊盘。
- SPI 扩展使用 SPI1：`PA4 / CS`、`PA5 / SCK`、`PA6 / MISO`、`PA7 / MOSI`，接口当前只带 `GND` 和信号，外设 `3.3V` 从公用扩展接口取电。
- 公用电源 + GPIO 扩展使用 `2x5` 排针，提供 `3.3V`、`GND`、`PA8`、`PB12`、`PB13`、`PB14`、`PB15` 和 `+5V_SYS`。
- `+5V_SYS` 来自 USB-C 输入经过保护/开关后的系统 5V，更适合作为 5V 输出取电点，不建议作为外部反灌供电入口。

### 8. LED 和按键

- 至少 2 个 LED：
  - 1 个电源指示 LED
  - 1 个用户 LED
- 至少 2 个按键：
  - 1 个复位按键
  - 1 个用户按键

### 9. 测试点

第一版必须重视可调试性，建议预留测试点：

- 5V
- 3.3V
- GND
- NRST
- SWDIO
- SWCLK
- USART TX/RX
- USB 转 UART 芯片关键电源
- ADC 分压后输入节点
- MOSFET 栅极
- MOSFET 输出端

## 非功能需求

- 原理图模块划分清晰，便于后续审查。
- PCB 使用 2 层板，优先保证可焊接、可调试和可制造。
- 器件优先选择常见、易采购、资料完整、适合手焊或练习焊接的型号。
- 文档需要记录需求、设计依据、风险点、调试计划、测试结果和制造输出。
- 第一版制造输出后续应包含 PDF 原理图、BOM、Gerber、装配/调试说明和测试记录。

## 待确认问题

- STM32F103C8T6 具体料号、封装、引脚分配和供电去耦细节。
- HSE 8MHz 晶振型号、负载电容、匹配电容和布局要求。
- USB-C 取电 CC 电阻、ESD/TVS、保险丝和输入滤波参数。
- USB 转 UART 芯片型号、供电方式、3.3V 逻辑电平、驱动支持、封装焊接难度和采购便利性。
- 3.3V 稳压方案、LDO 型号、压降、热耗散、板载负载电流和 3.3V 外供 100mA 裕量。
- 5V 引脚是否仅作为测试点/低风险扩展，若作为外供输出需重新核对保护、开关、保险丝和走线。
- ADC 分压比例、输入阻抗、RC 滤波参数、采样时间、钳位/TVS 方案和采样误差。
- MOSFET 型号、Rds(on)、3.3V 栅极驱动能力、封装散热、5V-12V VLOAD、感性负载续流和保护器件。
- SWD、UART2、I2C1、SPI1、公用电源 + GPIO、ADC、MOSFET 排针脚位定义和丝印命名。
- I2C 是否需要补 `R_SCL/R_SDA` 上拉预留焊盘。
- `+5V_SYS` 外引是否在丝印和文档中避免被误认为外部供电入口。
- PCB 70mm x 50mm 尺寸、安装孔数量/位置、接口朝向和测试点可达性。
