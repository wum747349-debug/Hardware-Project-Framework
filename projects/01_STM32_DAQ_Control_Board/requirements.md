# 项目需求

> 文档状态：当前有效
> 当前阶段：整板原理图系统审查
> 适用对象：STM32 DAQ Control Board Rev A
> 最后核对依据：当前原理图 PDF、当前 BOM 与已确认设计决定

## 项目名称

STM32F103C8T6 数据采集/控制开发板

## 核心目标

设计一块基于 STM32F103C8T6 的 2 层 PCB 开发板，用于训练 STM32 最小系统、电源输入与保护、USB 转 UART 通信、ADC 输入采集、MOSFET 低边控制输出、常用通信接口扩展、PCB Layout、上电调试和测试验证能力。

第一版优先保证：

- 可实现
- 可焊接
- 可调试
- 器件常见易采购
- 文档和制造输出完整

第一版不追求复杂功能，不做高速接口，不做大电流输出，不做高精度模拟前端。

## 功能需求

### 0. PCB 尺寸与机械边界

- 第一版 PCB 尺寸暂定约 `70mm x 50mm`。
- 后续可根据接口数量、测试点位置、安装孔、走线和布局情况微调。
- 可预留 2-4 个安装孔，具体孔径、位置和禁布区后续在 PCB 结构规划阶段确认。

### 1. MCU 最小系统

- MCU 型号确定为 `STM32F103C8T6`。
- 当前采用 LQFP48；进入 PCB Layout 前仍需核对原理图库引脚号、PCB 焊盘号和实际采购料号的一致性。
- 需要包含 STM32 最小系统：
  - 3.3V 供电
  - VDD / VDDA / VSS / VSSA 处理
  - 去耦电容
  - NRST 复位
  - BOOT 配置
  - SWD 下载调试接口
  - 外部高速晶振

### 2. 外部晶振

- 外部高速晶振频率确定为 `8MHz`。
- 当前 HSE 晶振为 `XC53G2-8.000-F12NJHP`，标称负载电容 `CL=12pF`。
- 当前 HSE 负载电容为 `C3/C4 = 5.1pF`，采购时选用 C0G/NP0 材质。
- HSE 晶振 PCB 布局仍需靠近 `OSC_IN/OSC_OUT`，走线短且对称、无过孔，并远离大电流和高速信号。

### 3. USB-C 供电与 USB 转 UART 通信

第一版不使用 STM32 原生 USB，不把 USB CDC 作为必做功能。

- USB-C 接口用于 5V 输入供电。
- USB-C 的 D+ / D- 连接 USB 转 UART 芯片，不连接 STM32 PA11 / PA12。
- STM32 PA11 / PA12 第一版完全不用作 USB 功能。
- USB 转 UART 芯片通过 TX/RX 与 STM32 USART 通信。
- 推荐使用 USART1：
  - USB 转 UART TXD -> STM32 USART1_RX / PA10
  - USB 转 UART RXD <- STM32 USART1_TX / PA9
- TX/RX 必须交叉连接。
- USB 转 UART 芯片与 STM32 之间的 UART 电平必须为 3.3V。
- 电脑端识别为 COM 串口，用于串口调试、打印日志、ADC 数据上传、MOSFET 控制命令下发和后续上位机通信实验。
- 当前实现摘要：板载 USB-UART 使用 `CH340C`，通过 USART1 PA9/PA10 与 MCU 通信；历史候选比较保留在 [docs/component_selection_plan.md](docs/component_selection_plan.md)。

### 4. 电源输入与保护

- USB-C 输入 5V。
- 5V 经电源保护和电源开关后，再转换为 3.3V。
- 3.3V 给 STM32、USB 转 UART 芯片逻辑侧、LED、接口上拉等低压电路供电。
- 需要包含：
  - 电源开关
  - 保险丝或自恢复保险丝
  - TVS / ESD 保护
  - 输入滤波
  - 3.3V 稳压电路
  - 电源指示 LED
  - 5V、3.3V、GND 测试点
- 可以单独预留若干个 `3.3V` 电源排针，用于给外部低功耗模块供电。
- 外部模块从板载 `3.3V` 取电时，最大电流限制为 `<=100mA`。
- `5V` 引脚主要用于测试点或低风险扩展。
- 后续若将 `5V` 作为外部供电输出，需要在原理图阶段结合 USB 输入保护、保险丝、电源开关和走线宽度重新核对。
- 3.3V 外供能力和 5V 扩展边界需要影响后续 LDO、保险丝、电源开关、电源测试点和排针选型。
- 当前 3.3V 稳压实现摘要：使用 `AP2112K-3.3TRG1`；具体外围电容、热耗散、封装和引脚映射仍需在原理图审查 / PCB Layout 前复核。

### 5. ADC 输入

- ADC 输入通道数：2 路。
- 板级外部接口输入范围：`0-5V`。
- STM32 ADC 引脚实际输入范围：`0-3.3V`。
- STM32 ADC 引脚不能直接承受 5V，外部 0-5V 信号进入 MCU 前必须经过缩放和保护。
- 第一版 ADC 主要用于低速电压采集和功能验证。
- 目标采样频率按每通道 `10Hz-1kHz` 级别考虑。
- 不用于高速波形采集，不追求高精度模拟测量。

每路 ADC 输入建议包含：

- 电阻分压，将 0-5V 缩放到 0-3.3V 以内
- 串联限流电阻
- RC 低通滤波
- 必要的钳位或 TVS 保护预留/评估
- ADC 输入测试点
- GND 引脚

后续分压电阻、RC 滤波、采样时间、输入阻抗和保护器件需要围绕低速采集目标核对。

### 6. MOSFET 低边输出

- MOSFET 输出通道数：2 路。
- 输出形式：N-MOSFET 低边开关。
- 面向小电流负载，不做大电流输出。
- MOSFET 负载电源允许外部输入。
- MOSFET 外部负载电源 `VLOAD` 第一版建议限制在 `5V-12V`。
- `VLOAD` 最大不超过 `12V`。
- 第一版主要面向 5V/12V 小电流低压负载。
- 外部负载电源必须与板子 GND 共地。
- 推荐使用电流：`<=300mA`。
- 设计目标可按 `<=500mA` 预留。
- 若驱动感性负载，必须考虑续流路径或保护器件。

每路 MOSFET 输出建议包含：

- STM32 GPIO 控制
- 栅极串联电阻
- 栅极下拉电阻
- 输出端排针
- 外部 VLOAD / OUT / GND 标识
- MOSFET 栅极和输出节点测试点

当前 MOSFET 实现摘要：使用 `AO3400A` 作为 2 路 N-MOSFET 低边输出主选；3.3V 栅极驱动能力、封装散热、VLOAD 范围、续流保护、接口和丝印仍需在审查中核对。

### 7. 接口形式

第一版接口形式暂定为排针。需要保留：

- SWD 下载调试接口
- USB-C 接口
- UART 通信/扩展接口
- I2C 传感器接口
- SPI 扩展接口
- 2 路 ADC 输入排针
- 2 路 MOSFET 输出排针
- 5V / 3.3V / GND 等电源测试点或扩展引脚

通信扩展接口电平边界：

- `UART / I2C / SPI` 扩展接口第一版均为 `3.3V` 逻辑。
- 不直接兼容 `5V` 逻辑信号。
- 如果外接 5V 模块，需要外部电平转换或重新评估保护方案。

当前接口实现摘要以 [design_notes.md](design_notes.md) 为准；本文只保留需求和边界。外部 UART、I2C、SPI、公用电源 + GPIO 均需有清晰丝印、电平边界和 GND 参考。

### 8. LED 和按键

- 至少 2 个 LED：
  - 1 个电源指示 LED
  - 1 个用户 LED
- 至少 2 个按键：
  - 1 个复位按键
  - 1 个用户按键

### 9. 测试点

第一版必须重视可调试性，建议预留测试点：

- 5V
- 3.3V
- GND
- NRST
- SWDIO
- SWCLK
- USART TX/RX
- USB 转 UART 芯片关键电源
- ADC 分压后输入节点
- MOSFET 栅极
- MOSFET 输出端

## 非功能需求

- 原理图模块划分清晰，便于后续审查。
- PCB 使用 2 层板，优先保证可焊接、可调试和可制造。
- 器件优先选择常见、易采购、资料完整、适合手焊或练习焊接的型号。
- 文档需要记录需求、设计依据、风险点、调试计划、测试结果和制造输出。
- 第一版制造输出后续应包含 PDF 原理图、BOM、Gerber、装配/调试说明和测试记录。

## 验收标准

- 原理图审查记录中所有高风险问题已关闭，未关闭问题有明确风险等级和处理计划。
- USB-C 仅 5V 输入、3.3V 外供 `<=100mA`、`+5V_SYS` 不作为外部反灌入口等边界在文档和丝印中可追溯。
- ADC 外部输入 `0-5V`、MCU ADC 输入 `0-3.3V`、`TP_ADC1/TP_ADC2` 对应关系清楚。
- MOSFET 输出 `VLOAD 5V-12V`、推荐 `<=300mA`、预留 `<=500mA`、外部共地和感性负载续流要求清楚。
- SWD、USB-UART、UART2、I2C1、SPI1、ADC、MOSFET、用户 LED/按键和测试点均有明确网络名或接口标识。
- 关键器件封装、引脚映射、焊盘映射、封装方向和关键参数在进入 PCB Layout 前完成 datasheet / reference manual / Altium 人工核对。
