# 立创商城搜索记录

## 使用原则

- 用户手动在立创商城搜索器件。
- AI/Codex 提供搜索关键词和筛选条件。
- 立创商品页用于查看 C 编号、库存、价格、封装、基础库/扩展库、资料入口。
- 最终设计参数必须回到 datasheet 核对。
- 不凭商品页截图或简介直接确定关键参数。
- AI/Codex 不默认自动爬取或批量下载立创商城资料。
