# 关键器件候选选型记录

## 当前阶段说明

本文件记录 `STM32F103C8T6 数据采集/控制开发板` 第一轮关键器件候选和 datasheet 初步核对结果。

当前阶段只用于收敛关键器件方向、记录初步依据、风险点和待核对项，不是最终 BOM，不进入完整原理图设计。普通阻容、LED、排针、测试点、普通按键、跳帽等后置外围器件，待模块电路参数明确后再选。

立创商城商品页只作为 C 编号、库存、价格、封装、基础库/扩展库状态和资料入口参考。最终设计参数必须回到 datasheet、reference manual 或 application note 核对。

### 关键网络与电源路径

| 网络 | 含义 |
|---|---|
| `VBUS_RAW` | USB-C 母座刚输入的原始 5V |
| `VBUS_FUSED` | 经过 F1 自恢复保险丝后的 5V 节点 |
| `+5V_SYS` | 经过 F1 和 SW2 后的板级系统 5V，供 AP2112 VIN 等后级使用 |
| `3.3V` | AP2112K 输出的板级 3.3V |
| `GND` | 板级参考地 |

当前路径为 `USB-C VBUS -> VBUS_RAW -> TP_VBUS -> F1 -> VBUS_FUSED`，其中 `D1 SMF5.0A` 从 `VBUS_FUSED` 并联到 `GND`，主电源路径继续经 `SW2 -> +5V_SYS -> TP_5V -> AP2112 VIN -> 3.3V -> TP_3V3`。

### AP2112K 外围与热耗散依据

| 项目 | 当前草图参数 | 依据 / 说明 |
|---|---|---|

### 风险与注意事项

| 编号 | 风险点 | 等级 | 处理建议 |
|---|---|---|---|
