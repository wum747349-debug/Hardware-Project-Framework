# 关键器件候选选型记录

## 当前阶段说明

本文件记录 `STM32F103C8T6 数据采集/控制开发板` 第一轮关键器件候选和 datasheet 初步核对结果。

当前阶段只用于收敛关键器件方向、记录初步依据、风险点和待核对项，不是最终 BOM，不进入完整原理图设计。普通阻容、LED、排针、测试点、普通按键、跳帽等后置外围器件，待模块电路参数明确后再选。

立创商城商品页只作为 C 编号、库存、价格、封装、基础库/扩展库状态和资料入口参考。最终设计参数必须回到 datasheet、reference manual 或 application note 核对。

## 选型风险表

| 编号 | 模块 | 器件 | 风险描述 | 风险等级 | 建议处理 |
|---|---|---|---|---|---|
| R-01 | 3.3V 电源 | AP2112K-3.3TRG1 | 5V 转 3.3V 为线性稳压，负载电流升高会带来热耗散风险 | 中 | 按 `P=(5V-3.3V)*Iout` 计算，第一版 3.3V 总电流长期建议控制在 150mA-200mA 以内 |
| R-02 | USB 转 UART | CH340C | 若 5V 供电后直接连接 STM32 UART，存在电平风险 | 高 | 按 3.3V 供电方案设计，VCC 接 3.3V，V3 与 VCC / 3.3V 连接 |
| R-03 | USB-C | TYPE-C 16PIN 2MD(073) | 0.5mm pitch 手焊和返修难度较高 | 中 | PCB Layout 阶段重点核对封装、阻焊、焊盘外露和可检查性 |
| R-04 | HSE 时钟 | XC53G2-8.000-F12NJHP | 当前资料未能确认负载电容 CL，可能影响 HSE 起振和频率误差 | 中 | 结合 STM32 官方资料和晶振完整型号编码表核对后再确定匹配电容 |
| R-05 | MOSFET 输出 | AO3400A | 驱动继电器、电机、电磁阀等感性负载时会产生反向能量和尖峰 | 高 | 必须额外考虑续流二极管或 TVS，不能只依赖 MOSFET 本体 |
| R-06 | ADC 输入保护 | 待定 | 保护器件漏电、电容和钳位电流可能影响采样精度或损伤 MCU | 中 | 结合 STM32 ADC 采样时间、输入阻抗和保护器件 datasheet 继续核对 |
