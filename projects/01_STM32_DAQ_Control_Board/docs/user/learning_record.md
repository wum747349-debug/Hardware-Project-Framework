## 2. 本阶段学习重点

- STM32F103C8T6 最小系统组成和常见检查项。
- USB-C 5V 取电、CC 下拉、VBUS 保护和 3.3V LDO 热耗散。
- CH340C 3.3V 供电和 USB 转 UART 连接方式。
- ADC 输入分压、限流、滤波、钳位和反灌风险。
- MOSFET 低边输出、续流二极管方向和外部共地要求。
- 文档结构如何服务原理图审查、PCB Layout 和后续展示。
