# 项目介绍

## 1. 项目目标

本项目是一块基于 `STM32F103C8T6` 的数据采集/控制练习板，目标是完整训练低压嵌入式硬件项目从需求、模块拆分、器件选型、原理图设计、审查、PCB Layout、上电调试到测试记录的流程。

第一版追求可实现、可焊接、可调试和文档清晰，不追求复杂功能、高速接口、大电流输出或高精度模拟测量。

## 2. 核心功能

- STM32F103C8T6 最小系统，包含 8MHz HSE、复位、BOOT0 和 SWD 调试接口。
- USB-C 5V 输入供电，板上生成 3.3V 系统电源。
- CH340C USB 转 UART，用于电脑端串口调试、日志输出和命令交互。
- 2 路 `0-5V` ADC 输入，进入 MCU 前经 `12kΩ/18kΩ` 分压、限流、滤波和钳位保护，5V 标称输入映射到约 3.0V。
- 2 路 N-MOSFET 低边输出，可控制 `5V-12V` 小电流负载。
- USART2 / I2C1 / SPI1 扩展接口、公用电源 + GPIO 扩展、PB5 用户 LED、PB8 用户按键和关键测试点。

## 3. 主要模块

| 模块 | 说明 |
|---|---|
| MCU 最小系统 | 完成 STM32 基础运行、下载调试和时钟配置 |
| 电源模块 | USB-C 5V 输入，保护后经 AP2112K 输出 3.3V |
| USB 转 UART | 通过 CH340C 实现电脑与 STM32 USART1 通信 |
| ADC 输入 | 支持两路低速 `0-5V` 电压采集训练 |
| MOSFET 输出 | 支持两路小电流低边开关控制训练 |
| 接口与测试点 | USART2、I2C1、SPI1、公用 GPIO、电源和关键测试点，提高后续 bring-up 效率 |

## 5. 项目边界

- USB-C 仅支持 5V 输入，不支持 USB-PD 9V/12V。
- 不使用 STM32 原生 USB。
- 通信扩展接口均为 3.3V 逻辑，不直接兼容 5V。
- 外部 UART 使用 USART2 PA2/PA3，PA9/PA10 保留给板载 CH340C 的 USART1。
- I2C1 已有 `R19/R20=4.7kΩ` 板载上拉到 3.3V；外部模块若也自带上拉，需检查并联后的等效上拉阻值和低电平灌电流。
- `+5V_SYS` 外引更适合作为 5V 输出取电点，不建议作为外部反灌供电入口。
- ADC 只用于低速功能验证，不用于高速波形采集或高精度测量。
- MOSFET 输出只用于小电流负载，推荐 `<=300mA`，设计预留 `<=500mA`。
- 当前处于阶段 11，剩余制造门禁关闭前不代表 PCB、DRC 或制造输出已经通过。
