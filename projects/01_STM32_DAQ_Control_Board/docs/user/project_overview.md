# 项目介绍

## 1. 项目背景和目标

本项目是一块基于 `STM32F103C8T6` 的数据采集/控制练习板，用于完整训练低压嵌入式硬件项目的需求拆分、器件选型、原理图设计、PCB Layout、调试验证和文档追溯。

第一版以可实现、可焊接、可调试和边界清晰为目标，不追求高速接口、大电流输出或高精度模拟测量。

## 2. 核心功能

- STM32F103C8T6 最小系统、8MHz HSE、复位、启动配置和 SWD。
- USB-C 5V 输入与板载 3.3V 电源。
- CH340C USB 转 UART 调试通信。
- 两路受保护的低速 `0-5V` ADC 输入。
- 两路面向小电流负载的 N-MOSFET 低边输出。
- USART2、I2C1、SPI1、GPIO、电源扩展、用户 LED/按键和关键测试点。

## 3. 技术亮点

- 将电源入口保护、数字控制、模拟采集和负载驱动组织在一块 2 层练习板上。
- 为外部模拟输入提供分压、限流、滤波和钳位保护链路。
- 板载 USB-UART 与外部 UART 分开分配，避免多个发送端直接冲突。
- 将设计意图、模块依据、EDA 证据、PCB 审查和制造门禁分层记录，便于追溯。

## 4. 主要模块

| 模块 | 作用 |
| --- | --- |
| MCU 最小系统 | 提供运行、时钟、复位、启动和下载调试基础 |
| 电源与保护 | 接收 USB-C 5V，经保护与开关后生成 3.3V |
| USB 转 UART | 提供电脑与 MCU 的串口通信入口 |
| ADC 输入 | 支持两路低速外部电压采集训练 |
| MOSFET 输出 | 支持两路小电流低边开关控制训练 |
| 接口与测试 | 提供通信扩展、人机输入输出和测量入口 |

## 5. 实现和验证范围

本项目覆盖从需求、器件与模块依据到原理图、PCB、制造准备、焊接和测试记录的完整训练路径。文档中的功能和设计意图不单独证明 EDA、DRC、制造或实测已经完成；实时阶段、硬件版本和下一步以项目根 [README.md](../../README.md) 为准，PCB 问题与制造门禁见 [PCB 审查记录](../pcb_review.md)。
