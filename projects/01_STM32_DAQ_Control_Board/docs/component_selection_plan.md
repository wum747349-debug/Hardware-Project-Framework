# 器件选型计划

## 0. 当前定位

本文是第一轮关键器件选型计划和历史选型依据入口。

当前项目已从“关键器件候选选型”推进到“模块原理图设计完成后的原理图系统审查准备”阶段。最终主选器件摘要、关键网络和模块设计依据以 [../design_notes.md](../design_notes.md) 和 [module_design/](module_design/) 为准。

本文保留原有选型计划、搜索关键词、筛选维度和候选记录模板，用于追溯第一轮器件选择过程；不作为最终 BOM，也不表示原理图已经审查通过。

## 1. 选型策略

第一轮选型阶段的策略是：只关注关键器件，不要求一次性收集所有元器件 datasheet。

- 第一轮关键器件会影响模块架构、供电、接口、电路参数、封装和 PCB Layout，应优先选候选。
- 外围器件后置，等模块电路参数明确后再选择。
- 立创商城由用户手动搜索、筛选、查看库存、价格、封装、基础库/扩展库状态，并下载 datasheet。
- AI/Codex 负责提供关键词、筛选条件、资料整理、datasheet 参数提取和候选对比。
- 立创商品页不能替代 datasheet。
- 关键参数必须回到 datasheet、reference manual 或 application note 核对。
- 当时该阶段不生成最终 BOM，不直接确定最终器件型号，不开始画原理图。

## 3. 第一轮关键器件

### STM32F103C8T6

- 为什么是关键器件：决定供电、引脚分配、SWD、BOOT、HSE、ADC、USART 和固件生态。
- 影响模块：MCU 最小系统、ADC 输入、USB 转 UART、MOSFET 控制、调试接口。
- 立创优先搜索：`STM32F103C8T6`、`STM32F103C8T6 LQFP48`。
- datasheet 核对：供电范围、LQFP48 引脚、VDD/VDDA 去耦、BOOT、NRST、SWD、HSE、ADC 输入范围和采样要求。

### USB 转 UART 芯片

- 为什么是关键器件：决定 PC 通信方式、驱动支持、USB D+/D- 连接、UART 电平和外围复杂度。
- 影响模块：USB-C 数据线、USART1、3.3V 供电、调试串口。
- 立创优先搜索：`CH340C`、`CH340N`、`CP2102N`、`FT232RL`、`FT230X`。
- datasheet 核对：3.3V UART 电平、供电方式、是否需要外部晶振、驱动支持、封装、D+/D- 典型连接和 ESD 建议。

### 3.3V LDO

- 为什么是关键器件：决定整板 3.3V 供电能力、压差、热耗散、输入输出电容和稳定性。
- 影响模块：MCU、USB 转 UART、LED、接口上拉、外供 3.3V 边界。
- 立创优先搜索：`3.3V LDO`、`500mA LDO`、`SOT-223 LDO`、`SOT-89 LDO`、`AMS1117-3.3`、`ME6211 3.3`、`HT7333`。
- datasheet 核对：输入电压、输出电流、压差、静态电流、热阻、输入输出电容容量和 ESR 要求。

### USB-C 母座

- 为什么是关键器件：决定 5V 输入、USB2.0 数据引出、CC 引脚、机械强度和 PCB 封装。
- 影响模块：USB-C 输入、电源路径、USB 转 UART、ESD/TVS、板边布局。
- 立创优先搜索：`TYPE-C 16P`、`USB-C 母座`、`USB2.0 Type-C`。
- datasheet 核对：VBUS/GND/CC1/CC2/D+/D- 引脚、固定脚、封装尺寸、推荐焊盘、机械强度和焊接难度。

### 8MHz HSE 晶振

- 为什么是关键器件：影响 STM32 外部高速时钟启动、稳定性、负载电容和 PCB 走线。
- 影响模块：MCU 最小系统、时钟配置、固件时钟树。
- 立创优先搜索：`8MHz 晶振`、`8MHz 3225`、`8MHz 5032`。
- datasheet 核对：频率、负载电容、ESR、频率精度、封装、驱动电平，并结合 STM32 HSE 要求计算匹配电容。

### 逻辑电平 N-MOSFET

- 为什么是关键器件：决定 3.3V GPIO 是否能可靠驱动外部低边负载，以及输出电流、热耗散和保护方案。
- 影响模块：MOSFET 低边输出、外部 VLOAD、续流二极管/TVS、输出接口和测试点。
- 立创优先搜索：`N MOS`、`逻辑电平 MOS`、`30V SOT-23 MOS`、`AO3400`。
- datasheet 核对：Vds、Id、Rds(on)、Rds(on) 的 2.5V/4.5V 测试条件、Vgs(th)、封装热能力和感性负载保护建议。

## 4. 第一轮暂不重点收集的外围器件

| 外围器件 | 后置原因 |
|---|---|
| 普通电阻 | 阻值、精度、功率和封装依赖分压、限流、上拉、下拉和栅极驱动计算 |
| 普通电容 | 容值、耐压、介质、ESR 和封装依赖 LDO、去耦、滤波和晶振要求 |
| LED | 电流和限流电阻依赖电源、亮度目标和功耗边界 |
| 普通排针 | 针数、间距和方向依赖接口定义和 PCB 布局 |
| 测试点 | 位置、形式和数量依赖原理图网络和布局可达性 |
| 普通按键 | 封装和连接方式依赖人机需求、复位/用户按键电路和布局 |
| 普通跳帽 | 是否需要、针数和位置依赖调试策略和接口边界 |

这些器件不需要在第一轮大量下载 datasheet。等关键器件和模块电路参数明确后，再按规格、封装、库存和可焊接性选择。

## 7. 当时建议的下一步

1. 用户先在立创商城手动搜索第一轮关键器件。
2. 每类先挑 2-3 个候选即可，不需要铺开所有外围器件。
3. 下载 datasheet 后放入 `references/datasheets/` 对应目录。
4. Codex 再整理 `references.md`。
5. AI 再读取 datasheet，做参数提取和候选对比。

当前项目已进入模块原理图设计说明完成后的原理图系统审查准备阶段；上述步骤作为历史选型过程追溯保留。
