# STM32 数据采集/控制开发板

## 项目目标

设计一块基于 STM32 的数据采集与执行控制开发板，用于训练 MCU 最小系统、电源设计、ADC 采集、数字通信、MOSFET 驱动和 PCB 设计能力。

## 第一版功能

- USB-C 5V 输入
- 3.3V 电源
- STM32 主控
- SWD 调试接口
- UART / I2C / SPI 扩展接口
- 2 路 ADC 输入
- 2 路 MOSFET 低边驱动输出
- 2 个按键
- 2 个 LED
- 关键测试点

## 设计限制

- 第一版使用 2 层 PCB
- 优先使用常见、易采购、易手焊器件
- 不做高速接口
- 不做大电流输出
- 所有关键电源和调试信号必须预留测试点
