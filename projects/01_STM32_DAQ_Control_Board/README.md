# STM32F103C8T6 数据采集/控制开发板

## 项目简介

本项目设计一块基于 `STM32F103C8T6` 的 2 层 PCB 开发板，用于训练 STM32 最小系统、电源输入与保护、USB 转 UART 通信、ADC 输入采集、MOSFET 低边控制输出、常用通信接口扩展、PCB Layout、上电调试和测试验证能力。

第一版目标是做出一块可实现、可焊接、可调试、器件常见易采购、文档和制造输出完整的练习板。不追求复杂功能，不做高速接口，不做大电流输出，不做高精度模拟前端。

## 第一版功能

- STM32F103C8T6 最小系统
- 8MHz 外部高速晶振
- USB-C 5V 输入供电
- 电源开关、输入保护、滤波和 3.3V 稳压
- USB-C D+ / D- 连接 USB 转 UART 芯片，电脑端作为 COM 串口通信
- USB 转 UART 与 STM32 USART1 通信，TX/RX 交叉连接，UART 电平为 3.3V
- SWD 下载调试接口
- UART / I2C / SPI 排针扩展接口
- 2 路板级 0-5V ADC 输入，进入 MCU 前经分压、滤波和保护限制到 0-3.3V
- 2 路 N-MOSFET 低边输出，面向小电流负载，外部 VLOAD 与板子 GND 共地
- 1 个电源指示 LED、1 个用户 LED
- 1 个复位按键、1 个用户按键
- 5V、3.3V、GND、SWD、UART、ADC、MOSFET 等关键测试点

## 第一版边界

- 不使用 STM32 原生 USB，PA11 / PA12 第一版不接 USB-C D+ / D-。
- 不把 USB CDC 作为第一版必做功能。
- 不允许将 0-5V ADC 外部输入直接接入 STM32 ADC 引脚。
- MOSFET 输出只做小电流低边开关，推荐使用电流 `<=300mA`，设计目标可按 `<=500mA` 预留。
- 关键器件型号和参数必须在后续器件选型/原理图阶段依据 datasheet、reference manual 或 application note 核对。
