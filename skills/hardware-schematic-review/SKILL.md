# Hardware Schematic Review Skill

## 适用场景

当需要审查原理图、PDF 原理图、Altium 截图、模块连接关系、接口定义或设计思路时，使用本 Skill。

本 Skill 用于在进入 PCB Layout 前发现电源、接口、保护、最小系统、模拟前端和调试可达性问题。

## 适用项目范围

本 Skill 默认服务当前仓库已有的三个硬件项目：

1. STM32 数据采集/控制开发板
2. 单节锂电池充电与保护电源板
3. STM32 + 运放 + ADC 模拟信号采集板

同时也适用于后续新增的低压嵌入式硬件、传感器采集、电源管理、模拟前端、MCU 控制类项目。

如果新增项目涉及高压、射频、高速数字、隔离电源、汽车电子、医疗电子或安规认证，需要在本 Skill 基础上增加专项检查项。

## 审查目标

原理图审查不是只判断“能不能连通”，而是要检查：

- 电源是否安全可靠
- MCU 最小系统是否完整
- 复位、BOOT、时钟、SWD 是否正确
- UART / I2C / SPI 接口方向和电平是否合理
- ADC 输入范围、滤波、限流和保护是否可靠
- MOSFET 驱动和负载保护是否完整
- 锂电池充电与保护是否安全
- 运放供电、输入输出范围和滤波是否合理
- 外置 ADC 和参考电压是否匹配
- 测试点是否足够
- 封装、BOM、丝印、接口定义是否一致

## 审查顺序

### 1. 总体结构审查

检查：

- 模块划分是否清晰
- 电源路径是否清楚
- 信号流向是否合理
- 网络命名是否一致
- 接口命名是否容易理解
- 是否存在跨页网络标签混乱
- 是否有必要增加功能框图或设计说明

### 2. 电源模块审查

检查：

- 输入电压范围是否符合需求
- USB-C 供电配置是否正确
- CC 电阻是否符合仅供电用途
- 是否需要保险丝、TVS、ESD 或反接保护
- LDO / DC-DC 输入输出电容是否符合 datasheet
- EN / FB / PG / GND 引脚连接是否正确
- 电源指示灯是否有限流电阻
- 3.3V、5V、VDDA 等关键电源轨是否有测试点
- 电源芯片功耗和温升是否有风险
- 模拟电源和数字电源是否需要滤波或隔离

### 3. STM32 最小系统审查

检查：

- VDD / VDDA / VSS / VSSA 是否完整连接
- 每个电源脚附近是否有去耦电容
- VDDA 是否有合理滤波和去耦
- NRST 复位电路是否合理
- BOOT0 / BOOT1 配置是否合理
- SWD 接口是否完整
- SWDIO、SWCLK、NRST、3.3V、GND 是否引出
- 晶振是否必要
- 晶振负载电容是否需要按 datasheet 和晶体参数计算
- 调试串口是否预留
- 未使用引脚是否有处理策略

### 4. 通信接口审查

检查：

- UART / I2C / SPI 方向是否正确
- I2C 是否有上拉电阻
- 上拉电阻电压是否正确
- 接口电平是否匹配
- 外部接口是否需要 ESD 保护
- 接插件引脚顺序是否容易接反
- 是否预留 GND 和测试点
- 接口丝印是否清晰

### 5. ADC 输入与保护审查

检查：

- ADC 输入电压是否不会超过 MCU 或外置 ADC 允许范围
- 是否有限流电阻
- 是否有 RC 滤波
- 是否有钳位、TVS 或其他保护
- 分压电阻阻值是否影响采样精度
- 信号源阻抗是否满足 ADC 采样要求
- ADC 参考电压是否稳定
- VDDA / VREF 去耦是否合理
- 是否预留模拟输入测试点
- 模拟地和数字地处理是否合理

### 6. MOSFET 输出审查

检查：

- MOSFET 类型是否正确
- Vds、Id、Rds(on)、Vgs 是否满足需求
- MCU GPIO 是否能可靠驱动
- 栅极电阻是否合理
- 栅极下拉电阻是否合理
- 感性负载是否有续流路径
- 负载接口是否有保护
- 大电流回路是否可能干扰 MCU 或 ADC
- MOSFET 封装散热是否足够

### 7. 锂电池充电与保护审查

检查：

- 充电芯片输入范围是否满足 USB-C 输入
- 充电终止电压是否适合单节锂电池
- 充电电流设置电阻是否正确
- 是否需要 NTC
- 电池接口极性是否明确
- 保护芯片连接方式是否正确
- 保护 MOSFET 方向是否正确
- 充电状态指示灯是否合理
- 电池电压是否有测试点
- 首次上电是否必须使用限流电源
- 是否有无人看管充电测试风险提示

### 8. 运放、外置 ADC 和参考电压审查

检查：

- 运放供电电压是否满足输入输出范围
- 输入共模范围是否覆盖目标信号
- 输出摆幅是否能覆盖 ADC 输入范围
- 带宽和压摆率是否满足目标信号频率
- 输入偏置电流是否影响测量精度
- RC 滤波参数是否合理
- ADC 输入范围是否匹配运放输出
- ADC 接口电平是否匹配 STM32
- 参考电压精度是否满足采样需求
- 参考电压噪声是否有风险
- 参考电压去耦是否合理
- 是否预留模拟前端测试点

### 9. 封装与可制造性审查

检查：

- 原理图库封装是否和采购型号一致
- PCB 封装是否和实物器件一致
- 极性器件方向是否明确
- 接插件脚位是否容易接反
- 测试点是否可接触
- 是否适合手工焊接
- 是否需要增加跳帽、0Ω 电阻或调试焊盘
- 丝印是否能帮助焊接和调试

## 输出格式

每次审查必须按以下格式输出：

### 当前结论

从以下三种中选择：

- 可以进入 PCB Layout
- 修改后再进入 PCB Layout
- 存在高风险，暂不建议进入 PCB Layout

### 问题清单

| 编号 | 模块 | 问题描述 | 风险等级 | 建议修改 |
|---|---|---|---|---|

### 需要核对 datasheet 的项目

| 器件 | 需要核对的参数 | 核对原因 |
|---|---|---|

### 建议增加的测试点

| 网络 | 测试目的 | 是否必须 |
|---|---|---|

### 下一步操作

说明：

- 哪些地方必须修改
- 哪些地方建议优化
- 哪些资料需要补充
- 是否需要重新审查
- 是否可以进入 PCB Layout

## 风险等级

- 高风险：可能损坏芯片、电池、电源，可能导致无法上电，或存在明显安全风险。
- 中风险：可能影响功能、稳定性、精度、温升、寿命或调试难度。
- 低风险：主要影响文档一致性、可读性、可维护性、丝印、测试便利性或后续整理。

## 结果记录

审查完成后，应提醒用户将结论写入或更新：

- 当前项目的 `docs/schematic_review.md`
- 当前项目的 `design_notes.md`
- 必要时更新 BOM
- 必要时更新 `requirements.md`
- 必要时更新 `docs/revision_history.md`

## 禁止事项

- 不要只说“看起来没问题”。
- 不要跳过电源、电池、ADC、MOSFET、运放、参考电压等高风险模块。
- 不要在没有 datasheet 依据时确认关键连接完全正确。
- 不要把开源项目原理图当作最终依据。
- 不要忽略测试点、调试接口和首次上电安全检查。
- 不要建议用户直接进入 PCB Layout，除非高风险项已经排除或明确标注为待验证。
