# Hardware Component Selection Skill

## 适用场景

当需要进行器件选型、替代料选择、BOM 初稿整理、关键器件确认或器件方案对比时，使用本 Skill。

本 Skill 应与 `skills/hardware-datasheet-reading/SKILL.md` 配合使用。涉及关键器件时，应先提取 datasheet 关键参数，再进行选型判断。

## 适用项目范围

本 Skill 默认服务当前仓库已有的三个硬件项目：

1. STM32 数据采集/控制开发板
2. 单节锂电池充电与保护电源板
3. STM32 + 运放 + ADC 模拟信号采集板

同时也适用于后续新增的低压嵌入式硬件、传感器采集、电源管理、模拟前端、MCU 控制类项目。

如果新增项目涉及高压、射频、高速数字、隔离电源、汽车电子、医疗电子或安规认证，需要在本 Skill 基础上增加专项检查项。

## 选型原则

第一版硬件项目优先选择：

- 常见型号
- 易采购
- 资料完整
- 官方资料清晰
- 有典型应用电路
- 有替代料
- 封装适合手工焊接或普通 PCB 打样
- Altium 符号和封装容易建立或检查
- 不追求过度复杂
- 便于测试和调试

## 选型流程

### 1. 明确需求

先从 `requirements.md` 中确认：

- 输入电压
- 输出电压
- 最大电流
- 接口数量
- ADC 通道数量
- 采样精度
- 负载类型
- 板子尺寸
- 调试方式
- 是否需要电池供电
- 是否需要低功耗
- 是否有特殊精度要求

如果需求不完整，应标注“不确定项”，不要强行确定关键器件。

### 2. 确认候选器件

每类关键器件建议至少给出：

- 1 个主选型号
- 1 个替代型号
- 如有必要，再给 1 个更易采购或更低成本型号

### 3. 核对 datasheet

必须核对：

- 工作电压范围
- 最大输入电压
- 输出电流或驱动能力
- 功耗与温升
- 封装
- 输入输出电容要求
- 引脚定义
- 典型应用电路
- PCB Layout 要求
- 采购和替代风险

### 4. 判断是否适合第一版

重点判断：

- 是否容易焊接
- 是否容易买到
- 是否容易调试
- 是否需要复杂外围电路
- 是否有足够测试点
- 是否容易替换
- 是否适合 2 层板

## 各类器件检查重点

### MCU

检查：

- 工作电压
- Flash / RAM
- GPIO 数量
- ADC 通道数量
- ADC 分辨率
- UART / I2C / SPI 数量
- SWD 调试
- CubeMX 支持情况
- Keil MDK 支持情况
- 封装焊接难度
- 是否适合当前项目复杂度

### USB-C 与供电入口

检查：

- USB-C 仅供电还是需要数据
- CC 电阻配置
- VBUS 电压范围
- 是否需要 ESD 防护
- 是否需要保险丝或限流器件
- 接口封装是否易焊接
- 接口机械强度

### LDO / DC-DC

检查：

- 输入电压范围
- 输出电压
- 输出电流
- 压差或效率
- 静态电流
- 输入输出电容要求
- EN / PG / FB 引脚
- 热设计风险
- 是否适合当前负载电流

### 单节锂电池充电与保护

检查：

- 输入电压范围
- 充电终止电压
- 充电电流设置方式
- 是否需要 NTC
- 充电状态指示
- 电池保护阈值
- 保护 MOSFET 方向
- 电池接口极性
- 首次上电和充电测试风险

### MOSFET

检查：

- N 沟道 / P 沟道
- Vds
- Id
- Rds(on)
- Vgs(th)
- 推荐 Vgs
- MCU GPIO 是否能可靠驱动
- 是否需要栅极电阻
- 是否需要栅极下拉电阻
- 感性负载是否需要续流路径
- 封装散热能力

### 运放

检查：

- 供电电压范围
- 输入共模范围
- 输出摆幅
- 带宽
- 压摆率
- 输入偏置电流
- 输入失调电压
- 噪声
- 是否适合单电源
- 是否适合目标信号频率和幅度

### 外置 ADC

检查：

- 分辨率
- 采样率
- 输入范围
- 接口类型
- 参考电压要求
- 输入驱动要求
- 模拟输入保护
- 电源和参考去耦
- 是否容易与 STM32 通信

### 参考电压源

检查：

- 输出电压
- 精度
- 温漂
- 噪声
- 输出电流
- 输入电压范围
- 去耦要求
- 是否满足 ADC 精度需求

### 保护器件

检查：

- TVS / ESD 工作电压
- 钳位电压
- 电容
- 响应速度
- 封装
- 是否影响信号质量
- 是否适合外部接口或模拟输入

### 接插件和测试点

检查：

- 引脚间距
- 是否防呆
- 是否易接反
- 是否方便万用表或示波器测试
- 是否适合手工焊接
- 是否有清晰丝印

## 风险等级

- 高风险：可能损坏芯片、电池、电源，可能导致无法上电，或存在明显安全风险。
- 中风险：可能影响稳定性、精度、温升、寿命、调试难度或后续改版。
- 低风险：主要影响成本、封装、采购、文档一致性或可维护性。

- BOM 草稿

## 禁止事项

- 不要直接照抄开源项目 BOM。
- 不要只给型号，不说明依据。
- 不要在没有 datasheet 依据时确认关键参数。
- 不要推荐明显采购困难、封装过难或资料不完整的器件作为第一版主选。
- 不要忽略替代料。
- 不要忽略锂电池、电源、MOSFET、ADC、运放、参考电压等高风险模块。
