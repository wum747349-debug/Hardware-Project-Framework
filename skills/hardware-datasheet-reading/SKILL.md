# Hardware Datasheet Reading Skill

## 适用场景

当需要阅读、提取、核对或整理器件 datasheet、reference manual、application note、evaluation board schematic 时，使用本 Skill。

本 Skill 主要用于为后续器件选型、原理图设计、原理图审查、PCB Layout 和上电调试提供依据。

## 适用项目范围

本 Skill 默认服务当前仓库已有的三个硬件项目：

1. STM32 数据采集/控制开发板
2. 单节锂电池充电与保护电源板
3. STM32 + 运放 + ADC 模拟信号采集板

同时也适用于后续新增的低压嵌入式硬件、传感器采集、电源管理、模拟前端、MCU 控制类项目。

如果新增项目涉及高压、射频、高速数字、隔离电源、汽车电子、医疗电子或安规认证，需要在本 Skill 基础上增加专项检查项。

## 使用前必须读取

在使用本 Skill 前，AI 应优先读取：

1. `PROJECT_RULES.md`
2. `AGENTS.md`
3. `docs/08_Project_Workflow.md`
4. 当前项目的 `requirements.md`
5. 当前项目的 `design_notes.md`
6. 当前项目的 `references.md`

如果当前项目文件尚未创建，应先提醒补充项目需求，再进行初步资料整理。

## 重点覆盖器件

本 Skill 重点覆盖：

- STM32 MCU
- LDO / DC-DC 电源芯片
- USB-C 供电相关器件
- 单节锂电池充电芯片
- 电池保护芯片
- MOSFET
- 运放
- 外置 ADC
- 参考电压源
- TVS / ESD / 保险丝 / 保护电阻
- 接插件、测试点、跳帽、指示灯

## 必须提取的内容

阅读 datasheet 时，至少提取以下内容：

### 1. 器件基本信息

- 器件型号
- 厂商
- 功能定位
- 推荐应用场景
- 封装类型
- 是否适合手工焊接或小批量打样

### 2. 工作条件

必须区分：

- Absolute Maximum Ratings，绝对最大额定值
- Recommended Operating Conditions，推荐工作条件
- Typical Characteristics，典型特性

不要把绝对最大额定值当作正常设计工作点。

### 3. 引脚功能

需要整理：

- 每个关键引脚功能
- 电源脚
- 地脚
- 使能脚
- 反馈脚
- 复位脚
- 通信接口脚
- 模拟输入输出脚
- 暴露焊盘或散热焊盘要求

### 4. 典型应用电路

需要提取：

- 官方典型应用电路
- 外围电阻电容推荐值
- 输入输出电容要求
- 反馈电阻计算方式
- 充电电流设置方式
- 参考电压去耦要求
- MOSFET 栅极电阻、下拉电阻建议
- ADC 输入滤波或保护建议

注意：典型应用电路只能作为依据，不能未经分析直接照抄。

### 5. 电气参数

根据器件类型提取关键参数：

#### MCU

- 工作电压范围
- Flash / RAM
- ADC 通道数量和分辨率
- GPIO 数量
- UART / I2C / SPI 数量
- SWD/JTAG 调试支持
- 时钟要求
- BOOT 配置
- 去耦建议

#### 电源芯片

- 输入电压范围
- 输出电压
- 输出电流
- 压差或效率
- 静态电流
- 输入输出电容要求
- 使能脚逻辑
- 热阻和功耗风险

#### 锂电池充电芯片

- 输入电压范围
- 充电终止电压
- 充电电流设置方式
- 充电状态指示
- 是否支持 NTC
- 热调节或热保护
- 电池反接或异常保护能力

#### MOSFET

- Vds
- Id
- Rds(on)
- Vgs(th)
- 推荐驱动电压
- 栅极电荷
- 封装热阻
- 是否适合 MCU GPIO 直接驱动

#### 运放

- 供电电压范围
- 输入共模范围
- 输出摆幅
- 输入偏置电流
- 输入失调电压
- 增益带宽积
- 压摆率
- 噪声
- 是否支持单电源工作

#### ADC

- 分辨率
- 采样率
- 输入范围
- 参考电压范围
- 接口类型
- 输入阻抗或采样电容
- 推荐前端驱动方式
- 参考电压和电源去耦要求

#### 参考电压源

- 输出电压
- 初始精度
- 温漂
- 输出噪声
- 输出电流能力
- 输入电压范围
- 去耦要求

### 6. PCB Layout 注意事项

需要提取：

- 去耦电容摆放要求
- 电源路径要求
- 模拟地和数字地处理建议
- 热焊盘处理
- 大电流路径
- 敏感模拟输入走线
- 参考电压走线
- USB / ESD 保护布局建议

### 7. 风险项

需要标注以下风险：

- 电压裕量不足
- 电流能力不足
- 功耗或温升风险
- 封装焊接难度过高
- 外围器件参数不明确
- 采购困难
- 替代料不足
- 典型应用和当前项目需求不完全匹配

## 风险等级

- 高风险：可能损坏芯片、电池、电源，或导致无法上电。
- 中风险：可能影响稳定性、精度、温升、寿命或调试难度。
- 低风险：主要影响成本、封装、采购、文档一致性或可维护性。

- 当前项目的 `references.md`

- 必要时更新 BOM 草稿
- 必要时更新 `requirements.md`

## 禁止事项

- 不要只根据教程、博客、论坛或开源项目确认关键参数。
- 不要把绝对最大额定值当成正常工作条件。
- 不要直接照抄典型应用电路而不分析项目需求。
- 不要在没有 datasheet 依据时确认充电电流、ADC 输入范围、MOSFET 驱动能力、运放供电范围、参考电压精度等关键参数。
- 不要忽略电源、电池、模拟前端和保护电路的安全风险。
