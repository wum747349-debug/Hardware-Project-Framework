# Hardware Datasheet Reading Skill

## 适用场景

当需要阅读、提取、核对或整理器件 datasheet、reference manual、application note、封装图或 evaluation board 资料时，使用本 Skill。

datasheet 阅读必须围绕当前模块和当前设计问题，不要求用户一次性阅读所有 PDF。

## 最小读取上下文

默认读取：

1. `PROJECT_RULES.md`
2. `AGENTS.md`
3. `docs/AI_Context_Guide.md`
4. `skills/hardware-datasheet-reading/SKILL.md`
5. 当前项目 `requirements.md`
6. 当前项目 `references.md`

按需读取：

- 当前项目 `design_notes.md`
- 当前模块相关 datasheet / reference manual / application note
- 相关 checklist

不默认读取：

- 所有项目目录
- 所有 Skill
- 所有 datasheet
- 模板目录
- 历史审查记录

## 核心原则

- 每次只针对当前模块、当前器件和当前设计决策提取关键参数。
- 不要求用户一次性阅读或下载所有 PDF。
- 普通阻容、LED、排针、测试点、普通按键等外围器件不作为第一轮 datasheet 阅读重点。
- 对立创商城下载的 datasheet，需要记录来源、器件型号、版本/日期和本地路径。
- 如果资料不完整、型号不清楚、版本不明或来源不可靠，需要提示回到厂商官网核对。
- 立创商品页不能替代 datasheet。
- 教程、博客、论坛、视频和开源项目不能作为关键参数唯一依据。

## 阅读流程

### 1. 明确当前问题

先确认本次阅读是为了回答什么设计问题，例如：

- MCU 最小系统供电、BOOT、NRST、SWD、HSE 如何连接？
- LDO 输入输出电容和热耗散是否满足？
- USB 转 UART 是否支持 3.3V UART 电平？
- MOSFET 在 3.3V 栅极驱动下 Rds(on) 是否足够低？
- ADC 输入保护是否会影响采样精度？

### 2. 确认资料身份

记录：

- 器件型号
- 厂商
- 资料类型
- 来源
- 版本 / 日期
- 本地路径或链接
- 是否与候选器件完全匹配

### 3. 提取本项目相关参数

只提取当前项目需要的参数，不做无目的全文搬运。

常见参数包括：

- Recommended Operating Conditions
- Absolute Maximum Ratings
- 供电范围
- 输入/输出范围
- 电流能力
- 热阻和功耗
- 引脚定义
- 外围电阻电容要求
- 典型应用电路
- 封装尺寸
- PCB Layout 注意事项

必须区分 Absolute Maximum Ratings 和 Recommended Operating Conditions，不能把绝对最大额定值当作正常工作点。

### 4. 提取典型应用和 Layout 注意点

提取官方典型应用电路中的：

- 必要外围器件
- 参数计算方法
- 输入输出电容要求
- 保护器件建议
- 去耦要求
- 热焊盘或散热建议
- 大电流路径、敏感信号和回流路径要求

典型应用电路只能作为依据，不能未经分析直接照抄。

### 5. 标注风险和待核对项

如果存在以下情况，应明确标注：

- 电压裕量不足
- 电流能力不足
- 功耗或温升风险
- 封装焊接难度过高
- 外围参数不清楚
- 资料来源不清楚
- 型号、封装或版本不匹配
- 采购或替代风险

## 常见模块提取重点

### MCU

- 工作电压范围
- Flash / RAM
- GPIO 数量
- ADC 通道和分辨率
- UART / I2C / SPI 数量
- SWD/JTAG 调试支持
- HSE 晶振要求
- BOOT 配置
- NRST
- VDD / VDDA / VSS / VSSA
- 去耦建议
- PCB Layout 建议

### LDO / DC-DC

- 输入电压范围
- 输出电压
- 输出电流
- 压差或效率
- 静态电流
- 输入/输出电容要求
- ESR 要求
- EN / PG / FB 引脚
- 热阻和功耗风险

### USB 转 UART

- USB 供电和 I/O 电平
- UART 电平是否支持 3.3V
- 驱动支持
- 内置晶振或外部晶振要求
- D+ / D- 连接和 ESD 需求
- 封装和引脚

### USB-C 连接器

- VBUS / GND / CC1 / CC2 / D+ / D- 引脚
- 封装尺寸
- 机械固定脚
- 推荐焊盘
- 是否适合手焊或当前工艺

### 晶振

- 标称频率
- 负载电容
- ESR
- 频率精度
- 封装
- 驱动电平
- PCB Layout 要求

### MOSFET

- Vds
- Id
- Rds(on)
- Rds(on) 测试条件
- Vgs(th)
- 推荐驱动电压
- 栅极电荷
- 封装热阻
- 是否适合 3.3V GPIO 直接驱动

### ADC 输入保护

- 工作电压
- 钳位电压
- 漏电流
- 电容
- 响应速度
- 对采样精度和输入带宽的影响

## 风险等级

- 高风险：可能损坏芯片、电源、电池，或导致无法上电。
- 中风险：可能影响稳定性、精度、温升、寿命或调试难度。
- 低风险：主要影响成本、封装、采购、文档一致性或可维护性。

## 禁止事项

- 不要只根据教程、博客、论坛或开源项目确认关键参数。
- 不要把立创商品页当作关键参数依据。
- 不要把 Absolute Maximum Ratings 当作正常工作条件。
- 不要直接照抄典型应用电路而不分析项目需求。
- 不要在没有 datasheet 依据时确认充电电流、ADC 输入范围、MOSFET 驱动能力、运放供电范围、参考电压精度等关键参数。
- 不要忽略电源、电池、模拟前端和保护电路的安全风险。
